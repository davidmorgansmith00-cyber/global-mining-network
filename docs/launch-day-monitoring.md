# Launch Day Monitoring

## Enhanced Alerting (First 24h)
- Error rate > 2% → Warning
- P99 latency > 500ms → Warning
- Any sustained 500 spike → Critical page

## Live Dashboard
- Real-time player count
- Blocks finalized per minute
- Average block time target < 5s
- Top error fingerprints
- On-call status and escalation chain

## Review Cadence
Operations reviews metrics every 5 minutes during launch window.
