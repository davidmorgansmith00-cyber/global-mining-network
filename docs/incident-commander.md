# Incident Commander Protocol

## Decision Tree
1. Is player impact active? If yes, classify as critical.
2. Is workaround available? If yes, communicate workaround immediately.
3. Should rollback execute? Decide within first 10 minutes.

## Communication Template
- "We are investigating [issue]. ETA [time]. Workaround: [details]."
- Post updates every 15 minutes until resolved.

## Roles
- Incident commander: decision authority and communications owner
- Tech lead: diagnosis and mitigation
- On-call engineer: implementation and verification
- Comms support: status page and social updates
