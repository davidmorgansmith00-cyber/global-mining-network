# On-Call Schedule

## Coverage Model
- **Launch Week:** 24/7 rotation with 3 teams, 8-hour shifts
- **Week 2-4:** 24/7 coverage with off-hours escalation
- **Month 2+:** Business-hours primary + escalation path

## Escalation Matrix
- First responder: triage within 15 minutes
- Tech lead: escalate if unresolved after 15 minutes
- CTO: escalate if unresolved after 30 minutes

## Handoff
- Shift handoff includes active incidents, open risks, and pending communication updates.
